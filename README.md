# Caesar Cipher 🔐

This is a Python project that I created to practise encryption and decryption using the Caesar Cipher technique.

The program shifts each letter in a message by a given number of positions in the alphabet.

## What can it do?
- Encrypt a message
- Decrypt a message
- Keep spaces and special characters unchanged
- Allow the user to play again without restarting the program

## Built With
- Python

## Concepts Used
- Functions
- For loops
- If-else statements
- Lists and strings
- Modulo operator

## Example

**Message:** learning never stops

**Shift:** 5

**Encrypted message:** qjfwsnsl sjajw xytux

## How to Run

Run the following command in your terminal:

```bash
python solution.py
```

*Note: Keep `art.py` in the same folder as `solution.py`, since the program uses it for the logo.*
